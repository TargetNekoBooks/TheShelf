Cloud Sync Setup

Your data will be saved to JSONBin — a free cloud storage service. It takes about 2 minutes to set up and your books will be available on every device.

  1. Go to jsonbin.io and create a free account
  2. Once logged in, click API Keys in the left sidebar
  3. Click Create Access Key — give it any name
  4. Copy the key and paste it below
